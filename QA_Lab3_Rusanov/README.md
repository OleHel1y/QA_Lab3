# VK Музыка — учебный проект {#mainpage}

Консольная модель раздела «Музыка» социальной сети ВКонтакте.
Автор: Русанов О.И., группа ИВТ-32.

\image html logo.png "Логотип раздела" width=180px

## Классы

| Класс | Назначение |
|-------|-----------|
| MediaItem | базовый медиаобъект (название, длительность) |
| AudioTrack | аудиозапись с автором, прослушиваниями и лайками |
| Song | песня (жанр, альбом) |
| Podcast | выпуск подкаста |
| Playlist | плейлист пользователя |
| Player | проигрыватель (конечный автомат) |
| MusicLibrary | библиотека «Моя музыка»: поиск, топ, рекомендации |

## Запуск

    cd src
    python main.py
